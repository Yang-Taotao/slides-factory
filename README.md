# slides-factory

This repository houses a few templates that I wrote for `latex` and `typst`.

## structure

```sh
.
├── assignment_template.typ
├── assignment.tex
├── assignment.typ
├── code
├── example
├── fig
├── LICENSE
├── preamble.tex
├── README.md
└── ref.bib
```

## instructions

Use your preferred editor to compile the `typst` and `latex` documents. Example compiled files are shown in `./example`.
